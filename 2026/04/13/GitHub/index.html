  我目前做的是在电脑上进行项目的开发、上传和下载。

###初始化仓库

  在GitHub上创建仓库后可以把本地的代码push到GitHub的仓库中。第一步是初始化仓库，这就需要git init指令。执行 git init 后，Git 会在当前目录下创建一个名为 .git 的隐藏文件夹。这个文件夹是非常重要的，因为它包含了版本控制系统的所有必要信息，如配置文件、分支、标签等。首先需要在终端中进入项目目录，例如项目在C盘的Ace文件夹中
